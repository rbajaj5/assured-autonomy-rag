# Data Boundaries

Included: first-party Python source, original rule documentation, synthetic regression fixtures, a small newly written teaching corpus, and source hashes. No claim of source ownership is made over upstream libraries.

Excluded: downloaded research PDFs, instructor slides and messages, classmates' submissions, corpus text caches, embeddings and indexes, private run reports, notebooks containing outputs, model weights, provider responses, credentials, and external repository clones. These remain in the local research workspace.

The application can rebuild an index from a corpus supplied by its user. That is not permission to redistribute the input corpus. API use can send retrieved passages to a provider; confirm both processing and transmission rights. Paper-card generation does not automatically eliminate copyright or privacy obligations.

The public test corpus is synthetic, not a sample copied from the actual class readings. Historical repaired/distilled card tests remain opt-in and are not silently replaced by fabricated research results. They expect the retained local files named by the original study.

GitHub stores the source; it is not hosting this RAG as a running service. A later hosted deployment would need separate credentials management, user authentication, corpus permissions, persistence, resource limits, and a privacy review.
